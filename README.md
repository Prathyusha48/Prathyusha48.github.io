# Prathyusha Buddha — Portfolio Website

A responsive single-page portfolio built around Prathyusha's Flutter/mobile engineering experience and applied AI work.

## Included

- Professional hero with portrait
- Experience and measurable impact
- Lumiseek + Health & Harmony production case study
- Direct Google Play and App Store links for both production apps
- VIBE AI case study with embedded mobile demo video
- Skills, education, certifications, contact information
- LinkedIn and GitHub integration
- Downloadable resume
- Responsive mobile navigation
- Light/dark theme
- Reduced-motion accessibility support

## Files

- `index.html` — site markup
- `styles.css` — responsive styling
- `script.js` — theme, navigation, reveal behavior
- `profile-photo.jpeg` — professional portrait
- `vibe-demo.mp4` — VIBE app demo
- `vibe-poster.jpg` — video poster image
- `Prathyusha_Buddha_Resume.pdf` — downloadable resume

## Run locally

Open `index.html` directly in a browser, or serve this folder with any static web server.

## Deployment

This is a static site and can be deployed to GitHub Pages, Netlify, Cloudflare Pages, or Vercel without a build step.
